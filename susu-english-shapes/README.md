# Susie's Shape Adventure

A small, bilingual English practice game for young learners. It covers:

- Shapes: diamond, oval, heart, crescent, star, and points
- The sentence pattern: “What shape is a starfish?” / “The starfish is a star.”
- Final consonant sounds `/k/` and `/g/`
- Touch-friendly quizzes, English speech, sound effects, and local progress

## Run locally

Open `index.html` directly in a modern browser. For the most reliable speech support, serve the folder with any static web server, for example:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

No build step or third-party dependency is required.
